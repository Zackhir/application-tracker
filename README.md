# JobTrackr – Job Application Tracker Web App

## Overview

**JobTrackr** is a responsive, frontend-only web application designed to help users track their job applications efficiently. Users can add, edit, delete, and manage applications with ease. The app is fully optimized for mobile and desktop and leverages **React**, **React Router**, and **Redux** for a smooth user experience.

---

## Features

- **Dashboard**  
  View a list of all job applications. Each entry displays:  
  - Company Name  
  - Job Title  
  - Application Status (Applied, Interviewing, Offer, Rejected)  
  - Applied Date  

- **Add Job Page**  
  Form to add a new job application with fields:  
  - Company Name  
  - Job Title  
  - Status (dropdown)  
  - Applied Date  
  - Notes  

- **Job Details Page**  
  View full details of a job application with options to:  
  - Edit the application  
  - Delete the application  

- **Sample Data Import**  
  Fetch sample applications from a public API for demo purposes.

- **Export & Import JSON**  
  Users can export their applications to a JSON file and import it back to restore data.

- **Responsive Layout**  
  Fully optimized for mobile, tablet, and desktop devices.

- **Animations**  
  Smooth reveal animations for a modern look.

---

## Tech Stack

- **Frontend:** React  
- **State Management:** Redux  
- **Routing:** React Router  
- **Storage:** localStorage (frontend-only)  
- **Styling:** Custom CSS  
- **API:** DummyJSON (sample data for demo)

## Usage

1. Navigate to **Add Job** to create a new application.  
2. View all applications on the **Dashboard**.  
3. Click an application to view details, edit, or delete it.  
4. Import sample data using the **Import Sample** button.  
5. Export your list using the **Export JSON** button and re-import when needed.
